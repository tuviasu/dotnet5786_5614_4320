# 📦 Delivery Management System (WPF / .NET)

A desktop application for managing deliveries in a computer equipment company.

## 🎯 Overview
This project simulates a delivery management system that manages orders, couriers, and system operations.  
It was built as part of an academic project, focusing on clean architecture and separation of concerns.

## 🏗️ Architecture
The system is built using a layered architecture:

- **DAL (Data Access Layer)** – handles data storage (List/XML)
- **BL (Business Logic Layer)** – contains business rules and logic
- **PL (Presentation Layer)** – WPF application using Data Binding

## ✨ Features
- Manage orders and couriers
- View delivery lists and details
- Update system configuration and clock
- Basic real-time updates using Observer pattern
- Multiple data storage implementations (List / XML)

## 🛠️ Technologies
- C#
- .NET 8
- WPF (XAML)
- LINQ
- XML Serialization

## 🎨 Design Patterns
- Singleton
- Factory
- Observer
